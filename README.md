# BBA MIC101 – Fundamentals of Entrepreneurship Live Quiz

- 10 Groups / Sets
- 10 MCQs per set
- 100 unique questions; no question is repeated across sets
- All four syllabus units represented in every set
- 15-minute timer per attempt
- Automatic submission when time expires
- Automatic score
- Student name and roll number
- One attempt per set per browser/device using localStorage
- Mobile-friendly
- Designed for GitHub Pages

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` to the root of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub Pages will publish the site. The live URL will normally be:
   `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

This is a static quiz. It calculates results in the student's browser; it does not send student responses to a central teacher database.
